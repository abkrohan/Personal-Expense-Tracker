# Personal Expense Tracker

CSE103: Structured Programming Project

## Description

A simple C-based Personal Expense Tracker that allows users
to add, display, search, update, and calculate expenses.

## Features

- Add Expense
- Display All Expenses
- Search by Category
- Update Expense
- Show Total Expense
- Save and Load Data from File

## Technologies

- C Programming Language
- Structures
- Arrays
- Functions
- File Handling

## How to Run

Compile the program using a C compiler and run the executable.
